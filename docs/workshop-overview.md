# Workshop Overview

This workshop is designed to teach you how to effectively use GitHub Copilot with the Azure Model Context Protocol (MCP) server to interact with Azure resources. By the end of this workshop, you will be able to use natural language queries to manage and work with various Azure services without remembering complex CLI commands.

## Learning Objectives

- Understand how GitHub Copilot Agent works with external tools like Azure MCP
- Learn how to create, manage, and query Azure resources using AI-powered assistance
- Master the use of Azure MCP to interact with various Azure services
- Implement AI-driven workflows to streamline Azure resource management
- Create and manage resources using Azure CLI with GitHub Copilot's help

## Workshop Modules

### Module 1: Resource Groups

- Introduction to Azure MCP and GitHub Copilot integration
- List and explore resource groups
- Work with resource group metadata

### Module 2: Azure Storage

- Create and manage storage accounts
- Work with blob containers and blobs
- Explore Azure Tables
- Retrieve container properties and metadata

### Module 3: Azure AI Search

- List Azure AI Search services
- Explore search index schema and configuration
- Perform search queries against indexes
- Analyse search results

### Module 4: Azure Cosmos DB

- List and explore Cosmos DB accounts
- Manage databases and containers
- Insert and query items
- Execute SQL queries against containers

### Module 5: Azure Monitor

- List and explore Log Analytics workspaces
- Write and execute KQL queries
- Analyse logs and metrics
- Explore available monitoring tables

### Module 6: Azure Key Vault

- List and explore Azure Key Vaults
- Create and manage keys
- Work with secrets and certificates
- Implement security best practices

## Workshop Flow

Each module includes:

1. **Introduction & Concepts**: Key ideas and services explained
2. **Hands-on Exercises**: Step-by-step tasks to complete
3. **Challenge Tasks**: Apply what you've learned to solve real problems
4. **Knowledge Check**: Verify understanding with questions

## What You'll Create

Throughout this workshop, you'll build and interact with a complete Azure solution that includes:

- Storage for data ingestion and processing
- Cosmos DB for structured data storage
- Azure AI Search for enhanced search capabilities
- Log Analytics for monitoring and troubleshooting
- Key Vault for secure secret management

## Prerequisites Knowledge

- Basic understanding of cloud computing concepts
- Familiarity with Azure services is helpful but not required
- Basic terminal/command-line experience
- No prior GitHub Copilot experience required
